[h1]2.31c[/h1]

A small pass. Two bug fixes, and a tidy-up that only shows itself if you run a compatibility patch.

[h2]Bug Fixes[/h2]
[list]
[*][b]Fixed the Mikaelson men keeping their beards.[/b] The rule that shaves them was correct and had been dead script for a while — the group held two entries with the same name and the later one won, and four of the five comparisons pointed at Mikael instead of their own character. Both fixed.
[*][b]Fixed the version popup announcing the previous version.[/b] Third place the version number lives, and it had fallen behind again.
[/list]

[h2]Compatibility[/h2]
[list]
[*][b]Ten more places now ask "is this a valid target?" before changing what someone is.[/b] The mod already asked at every interaction you click. It did not ask on the paths you don't click — the yearly trait sweep, the witchcraft dynasty legacy, a mythical legend's reward, a court mage picking his own curse victim, a cult priest appointment, the place-of-power sweep, the werewolf bite chain, and a war whose victory converted every character of an entire faith at once. All of them go through the same check now.
[*][b]On its own this changes nothing.[/b] The check answers yes for everyone unless a compatibility patch says otherwise. If you run A Game of Thrones with the compatibility patch, it means dragons and the walking dead are no longer quietly eligible for any of the above.
[/list]

[h2]Note[/h2]
[list]
[*]Safe to drop onto a running save.
[*]If you run A Game of Thrones, this pairs with the AGOT: Supernatural & The Long Night Compatibility Patch 1.1.3 — the beard fix and the compatibility work each need both mods updated to reach you.
[/list]
