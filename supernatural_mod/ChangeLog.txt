SUPERNATURAL -- CHANGELOG

v2.30
- FIX: custom localization for secret descriptions was replacing the base game's list instead of adding to
  it, which deleted all ten vanilla secret descriptions (the fallback included) for everyone running the
  mod. All ten are restored; Supernatural's four supernatural secrets are unchanged, byte for byte.
- NEW (separate mod): "AGOT: Supernatural & The Long Night Compatibility Patch" -- if you run Supernatural
  together with A Game of Thrones and/or AGOT: The Long Night & Azor Ahai, subscribe to the patch and put
  it LAST in your load order. Twenty-two entries both mods define are merged there so neither mod silently
  erases the other's work: marriages, secrets, disinheritance, the witch ritual, birth events, schemes,
  abductions and more.

- FIX: the magic-artifact pulse (magic_ev.99) scanned every living character each firing and, in
  observer mode, found no player at all -- then read that empty result once per candidate ruler
  (14,000+ script errors in one evening's log). It now uses the player list directly and checks
  the scope exists before reading it.

LOAD ORDER when running with AGOT:
  1. A Game of Thrones
  2. AGOT submods
  3. AGOT: The Long Night & Azor Ahai (optional)
  4. Supernatural
  5. AGOT: Supernatural & The Long Night Compatibility Patch -- ALWAYS LAST

v2.29 and earlier: see the workshop page.
