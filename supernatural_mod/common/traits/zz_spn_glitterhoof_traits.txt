# Supernatural 2.41 -- Glitterhoof (WORK-ORDER-2.41 §3.3). After Buck's "horse" trait, with his permission.
# Namespaced spn_horse so it never collides with Buck's own mod if both are loaded.
#
# What changed from Buck's, and why:
#   - fertility = -1.0, not can_have_children = no. An unblessed horse never conceives; Blessed by the Stables
#     (+1.0, zz_spn_glitterhoof_modifiers.txt) cancels it. can_have_children = no could not be undone.
#   - no flag = can_not_marry and no inheritance blockers. Marriage is gated by the VARIABLE can_not_marry, which
#     vanilla's can_marry_common_trigger also reads (00_marriage_triggers.txt:21), so the player's one unlock can lift
#     it. A foal of a noble house can inherit (Thomas, 2 Nov: "you giving permission in your world for possible
#     horse takeovers").
#   - prowess -10 as well: with every skill at -10 he is never anyone's knight (vanilla has no trait flag for that;
#     _traits.info lists none, and vanilla's own flags were enumerated 2 Nov).
#   - not a health trait, not in the ruler designer.
spn_horse = {
	diplomacy = -10
	intrigue = -10
	stewardship = -10
	martial = -10
	learning = -10
	prowess = -10
	fertility = -1.0

	disables_combat_leadership = yes
	shown_in_ruler_designer = no
	attraction_opinion = -50
	ai_energy = -50

	desc = {
		first_valid = {
			triggered_desc = {
				trigger = { NOT = { exists = this } }
				desc = trait_spn_horse_desc
			}
			desc = trait_spn_horse_character_desc
		}
	}
}
