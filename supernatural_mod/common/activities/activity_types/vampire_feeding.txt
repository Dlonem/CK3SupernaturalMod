		}
	}

		# Cheapest test first: province_filter is `all` now, so this runs against every province
		# in the world when the planner opens. city_holding stays first to keep the short-circuit.
		# 2.34: tribal holdings too -- a tribal ruler in an early tribal region had no city within reach and could never

		OR = {

		# 2.32 -- and this is the leash. `large` is vanilla's own "roughly one France away", which

		# Constantinople on the menu from Ireland. Travel time does the rest of the limiting.
		# This is the tuning knob if the range ever feels wrong: small / medium / large / huge.
		# The threshold is its own script value so the AGOT patch can retune it for that map.
		# 2.35a -- WRAPPED, same defect as the hunt: the bare comparison printed
