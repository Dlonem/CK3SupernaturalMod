# file keeps vanilla's name, so it replaces vanilla's file outright and no holding type is ever defined twice.

# MAINTENANCE: whenever a CK3 patch changes common/holdings/00_holdings.txt, copy the new vanilla file over this one and
# add the three spn_order_collegium_01 lines again (search for "Supernatural 2.39"). Until then this copy hides whatever
# the patch changed in the holding types. With another mod that ships its own 00_holdings.txt (AGOT), whichever loads
# last wins: the compatibility patch must then ship that mod's file with the Collegium added and load after both.
# Listed in overrides.info.
