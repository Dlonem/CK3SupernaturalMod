# Supernatural 2.41 -- FEAR. CK3 1.21 moves every county's control toward a baseline, so a one-off drop now heals by
# itself. Thomas, 17 Nov 2026: a hit should lower the baseline "for like the next year, unless cleared early by a
# hunter"; a vampire who keeps preying on the same place keeps it down "very long term"; and a town he passed through once
# must not suffer forever, because "a hunter is going to come through and not find anything... I'm long gone by then",
# and the world must not depend on there being hunters at all.
#
# COUNTY modifiers, one tier at a time, each lasting one year from the LAST incident (spn_menace_fear_rise_effect,
# zz_spn_menace_effects.txt). Tiers match vanilla 1.21 Typhus's control baselines (-5 / -10 / -15). Cleared with the
# trail by spn_menace_clear_county_effect (a hunter's kill, an exorcism, the Powder, a relic, the culprit's death).

	icon = county_modifier_control_negative
	control_baseline_add = -5
}
spn_menace_fear_2_modifier = {
	icon = county_modifier_control_negative
	control_baseline_add = -10
	popular_opinion_add = -5 # people start to ask why their lord does nothing
}
spn_menace_fear_3_modifier = {
	icon = county_modifier_control_negative
	control_baseline_add = -15
	popular_opinion_add = -10
}
