# Supernatural 2.41 -- Silk & Silver. The menace reaches the market (Thomas, 17 Nov 2026: "vampire or werewolf menace in a
# county is the obvious link to supply and prices. Absolutely.").
#
# TRADE MARKET modifiers, put on the county's market (title_province.barony.trade_market, vanilla 1.21's own path) by
# spn_menace_market_effect for one year from the last incident, and taken off when a hunter clears the trail. The shape is
# vanilla's market banditry (gdp_market_banditry_trade_modifier): small price multipliers by goods category.
#   vampire  -- people stop going out after dark: taverns, comforts and fine things sell for less.
#   werewolf -- the roads are not safe: everything costs more to buy, sells for less, and routes through it carry less.
#   demon    -- things spoil: staple goods cost more.
#   witch    -- the harvest fails: crops cost more.
spn_menace_market_vampire_modifier = {
	icon = trade_goods_negative
	trade_category_alcohol_sell_price_mult = -0.05
	trade_category_comforts_sell_price_mult = -0.05
	trade_category_luxury_consumption_sell_price_mult = -0.03
}
spn_menace_market_werewolf_modifier = {
	icon = mask_negative
	trade_category_all_buy_price_mult = 0.02
	trade_category_all_sell_price_mult = -0.02
}
spn_menace_market_demon_modifier = {
	icon = trade_goods_negative
	trade_category_staple_goods_buy_price_mult = 0.03
}
spn_menace_market_witch_modifier = {
	icon = trade_goods_negative
	trade_category_crops_buy_price_mult = 0.03
}
