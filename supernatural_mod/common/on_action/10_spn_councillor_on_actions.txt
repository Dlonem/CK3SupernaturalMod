# Supernatural -- the spymaster's Find Secrets reveal list.
#
# RESTORED 21 Aug 2026. Every one of the base game's fourteen reveals had been commented out here,
# leaving only Supernatural's four -- so the spymaster could not uncover a Deviant, a murderer, a
# lover, an unbeliever, incest, a witch, a bastard or a crypto-religionist. spymaster_task.0359, the
# FALLBACK that exists so a successful task always resolves into something, was switched off with
# them, so a success against a target with none of the four supernatural secrets simply produced
# nothing at all.
#
# first_valid fires the first entry whose trigger passes, so ordering is the whole design: the four
# supernatural reveals stay exactly where their author placed them -- after 0349, ahead of the
# bastard and crypto-religionist checks -- and keep priority. The fallback is last, where it belongs.
#
# spymaster_task.0353 (Secret Crypto-Religionist) had never even been commented out: this file
# predates it. It is in the list now.
#
# The compatibility patch ships the same list built from AGOT's copy rather than the base game's,
# because AGOT can add to it.

	first_valid = {
		spymaster_task.0341 #Secret Deviant

		spymaster_task.0344 #Secret Murder

}
