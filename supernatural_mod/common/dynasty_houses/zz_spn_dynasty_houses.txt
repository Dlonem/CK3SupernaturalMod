# 2.39 (WORK-ORDER-2.39 F10): House Morningstar.
#
# A house of Witchcraft's Hell dynasty (hell_dynasty, common/dynasties/01_dynasties_hell.txt), declared the same way as
# Witchcraft's own house_maledictio (common/dynasty_houses/01_dynasty_houses_hell.txt): it points at hell_dynasty and
# names no culture of its own, because a house takes its dynasty's culture. A total conversion such as AGOT needs
# nothing for it. It starts with no members, as house_maledictio does; nothing in 2.39 puts anyone in it. A script that
# wants to can use `dynasty_house = house:house_morningstar` in a character template, or `set_house` on a character.
# Witchcraft's houses file is left byte-identical to Witchcraft 2.18; this file is Supernatural's own.
#
# Said plainly: "Morningstar" is Lucifer's surname in DC's Lucifer (TV, 2016-2021), not in Supernatural, where he has
# none. "Morning star" itself is the old epithet (Isaiah 14:12), and that is the sense used here. Witchcraft already
# writes Lucifer as the master of Bael, Abraxas, Astaroth and Asmodeus. The motto is "Non serviam", "I will not serve"
# (the Vulgate's Jeremiah 2:20, long put in Lucifer's mouth).
#
# The runway, written down and not built: in Supernatural, Lilith breaks 66 seals. The last seal is the first demon's
# death; the Cage opens and Lucifer walks. The Horsemen's four rings are the four keys back into the Cage. In CK3 the
# natural host is a 1.20 world situation (common/situation) whose phases are the seals. Pieces that already exist and
# would feed it: Witchcraft's endgame crises rule (magic_endings), Bael, the Seal of Solomon, demons and the Compact.
# Nothing in 2.39 makes that harder later.

	name = "spn_house_morningstar"
