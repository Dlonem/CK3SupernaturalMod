# Supernatural -- SPECIES GATE.
#
# WHAT THIS IS. Every power in this mod -- turning, biting, training, and all 54 magic interactions --
# assumes its target is a person. In this mod alone that assumption is always true, so it was never
# written down. Loaded next to a total-conversion it stops being true: A Game of Thrones makes dragons
# real characters who sit in your court, appear in every character list, and pass every gate this mod
# has, so a vampire could embrace a dragon and a mage could dominate one.
#
# HOW IT WORKS. This trigger is a HOOK, not a rule. On its own -- Supernatural without any total
# conversion -- it answers "yes, that is a valid target" for everybody, so nothing about this mod
# changes by one point. A compatibility patch that knows what the non-people in its world are called
# overrides this ONE key and the whole mod inherits the answer: interactions, initialisation events,
# spell immunity, all of it.
#
# WHY IT IS A HOOK AND NOT `NOT = { has_trait = dragon }`. `dragon` is not a trait this mod defines.
# Naming a trait that does not exist is an error on every single evaluation for every player who runs
# Supernatural by itself, which is most of them.
#
# WHERE IT IS WIRED IN:
#   common/character_interactions/10_spn_confer_interactions.txt   -- the turning chain
#   common/character_interactions/00_magic_interactions.txt        -- the spell list
#   common/character_interactions/10_spn_interactions.txt          -- compulsion and the bond
#   common/scripted_triggers/magic_triggers.txt                    -- the has_immunity_for_* family
#   events/supernatural_events/10_spn_initiate_events.txt          -- the hard backstop
#
# THE BACKSTOP MATTERS MOST. An interaction gate is a button; the initialisation events are the only
# door into the four creature traits, so a clause there covers every route including AI actions,
# activities and events nobody has thought about yet.

spn_is_valid_supernatural_target = {
	always = yes
}
