# Supernatural 2.41 (11 Nov 2026) -- THE THREE PATHS SHARE THE BASICS.
#
# 2.38e made Mage, Warlock and True Witch exclude each other. Witchcraft's own road to Mage ran THROUGH True Witch (only a
# True Witch could host the Artifact Search, an artifact opens the Arcane focus, the Arcane tree ends in Mage), so the
# rule closed that road (Steam, static pump, 11 Nov). Thomas: "if you get Warlock, then you can do a lot of the base
# level stuff that Mage and True Witch can do. And the same thing should apply to Mage, and to Witch ... you fall under
# one of three different types of groups of magical practitioners."
#
# CHARACTER scope. Someone who has finished any one of the three paths. A false Mage holds the Mage trait and counts.
# Shared through this trigger (apply_upstream_edits.py carries each Witchcraft line): hosting the Artifact Search,
# attending a Mage Summit, building the Mage Tower on an estate, the Court Mage's aptitude and candidate score, the cult
# priest's aptitude, the adventurer contracts that asked for a True Witch or a Mage, and commissioning or unbinding the
# Chains. Kept to one path: everything else that names a single trait (the Mage's duel, spells, council and Order; the
# True Witch's initiation and Yaga's seat; the Warlock's bargains).
# CHARACTER scope. Who may host the Artifact Search. 2.41 audit: any witch. The search is one of the ways to the Arcane
# focus, so asking for a finished path kept a plain witch from ever reaching Mage this way (XO, Steam, Nov 2026).
spn_may_host_artifact_search_trigger = {
	OR = {
		spn_finished_practitioner_trigger = yes
		has_trait = witch
		any_secret = { secret_type = secret_witch }
	}
}

spn_finished_practitioner_trigger = {
	OR = {
		has_trait = archmage
		has_trait = true_witch
		has_trait = warlock
	}
}
