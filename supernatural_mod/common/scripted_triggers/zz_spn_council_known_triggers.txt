# Supernatural 2.39 -- who knows the Gnostic Council is there (the Boot 1 fixes, 16 Oct; tool/pkgs/PB/HANDOFF.md).
#
# Thomas's boot: "Make a donation to the Gnostic Council" showed to a witch who is not of the Order and had never heard of
# it, and its tooltip named every seat holder (the +5 opinion each of them gives). With the Order rule On the council is
# the Order's (2.38b, DESIGN-2.38b §3), and the council's own HUD button is shown to members only (generator entries 29
# and 30, global spn_order_council_ours). The donation, "Ask the Grand Magus for support" and "Ask for a seat on the
# Gnostic Council" now follow the same rule. Without that, a menu entry that appears on one portrait only would point at
# the Grand Magus (the B6 rule).

# CHARACTER scope. For is_shown only (it prints no line). True when the council is not the Order's (the rule Off, or a
# save from before 2.38b), when Witchcraft has revealed the council to the world (mc_revealed), or for a member of the
# Order or of the council.
spn_order_council_known_trigger = {
	OR = {
		NOT = { exists = global_var:spn_order_council_ours }
		exists = global_var:mc_revealed
		spn_is_order_member_trigger = yes
		has_variable = mc_member_var
	}
}
