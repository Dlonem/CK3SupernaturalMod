# THE ONE CHAMPION-LIST HELPER (F4 + C10). Root/this = the candidate; scope:spn_fit_hide = the hide's flag.
# Walks the hide's own record of its champions (spn_hide_<hide>_champions, written at every choosing by
# spn_hide_make_champion_effect step 5, read nowhere before 2.40) once, skipping the candidate himself, and adds per earlier
# champion:
#   - count mode (scope:spn_lin_count_mode saved; C10 "the strength passed on"): 1;
#   - otherwise (F4 lineage): parent 15, sibling 10, grandparent 8, else 0; and, only for kin, +5 if he kept Bond 75 or more or
#     left his mark (global list spn_hide_<hide>_honoured), +5 if he died wearing it (spn_hide_<hide>_died_wearing); both
#     recorded at exit from 2.40 on, in global lists because a dead character's variables cannot be read.
# `prev` inside the walk is the candidate: never `root`, because spn_hide_fit_value is also read in order_by and weight blocks
# whose root is someone else (the Gathering's host, the hide's keeper).
# Dead men stay valid scopes in a global list; kin triggers read them as they were.
# ==================================================================================================
spn_hide_lineage_walk_value = {
	value = 0
	if = {
		limit = {
			scope:spn_fit_hide = flag:silverback
			has_global_variable_list = spn_hide_silverback_champions
		}
		every_in_global_list = {
			variable = spn_hide_silverback_champions
			limit = { NOT = { this = prev } }
			if = {
				limit = { exists = scope:spn_lin_count_mode }
				add = 1
			}
			else_if = {
				limit = {
					OR = {
						is_parent_of = prev
						is_sibling_of = prev
						is_grandparent_of = prev
					}
				}
				if = {
					limit = { is_parent_of = prev }
					add = spn_hide_kin_parent_value
				}
				else_if = {
					limit = { is_sibling_of = prev }
					add = spn_hide_kin_sibling_value
				}
				else = {
					add = spn_hide_kin_grandparent_value
				}
				if = { # Boot 2 fix: global lists (a dead man's variables cannot be read)
					limit = { is_target_in_global_variable_list = { name = spn_hide_silverback_honoured target = this } }
					add = spn_hide_kin_good_value
				}
				if = {
					limit = { is_target_in_global_variable_list = { name = spn_hide_silverback_died_wearing target = this } }
