# Supernatural 2.36 -- how far one act moves Spiritual Fulfillment, before the character's own multipliers.
# Read by common/scripted_effects/zz_spn_fulfillment_effects.txt, which also decides WHETHER an act moves anything
# (a Rite only condemns a creature that is known for what it is).
#
# Vanilla's scale (pam_values.txt): miniscule 1, minor 3, medium 5, major 10, massive 20. For comparison, vanilla's own
# direct losses for a plot: major for starting a murder while holding indulgences, medium for the other hostile schemes in
# the same position (00_scheme_interactions.txt). Everyone else's scheme cost comes from stress_and_fulfillment_impact.
#
# These are the base sizes. The engine then applies the character's own fulfillment multipliers, and those are where
# "how much do you care" lives:
#   cynical  -75% loss, -25% gain     zealous  +100% loss, +25% gain     (vanilla, 00_traits.txt)
#   a KNOWN creature whose Rite outlaws its kind -25% gain and loss, shuns it -10%  (10_spn_traits.txt, rite_modifier)
# So under a Rite that outlaws vampirism a feed costs a known zealous vampire 5.25, a known ordinary one 2.25, and a
# hidden one nothing. A cynic is not charged at all: zz_spn_fulfillment_effects.txt skips him outright rather than
# trusting the multipliers to cancel.
#
# Set any of these to 0 to switch that act off.

spn_fulfillment_feed_value = minor_spiritual_fulfillment_value		# a feed the victim walks away from
spn_fulfillment_kill_value = medium_spiritual_fulfillment_value		# a kill by fang or claw, or a compelled death
spn_fulfillment_make_value = major_spiritual_fulfillment_value		# turning someone into your own kind
spn_fulfillment_slay_value = minor_spiritual_fulfillment_value		# a hunter putting a creature down

spn_fulfillment_feed_loss = { add = spn_fulfillment_feed_value multiply = -1 }
spn_fulfillment_kill_loss = { add = spn_fulfillment_kill_value multiply = -1 }
spn_fulfillment_make_loss = { add = spn_fulfillment_make_value multiply = -1 }
spn_fulfillment_slay_loss = { add = spn_fulfillment_slay_value multiply = -1 }
